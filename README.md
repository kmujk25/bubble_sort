# 버블 정렬 시각화

버블 정렬이 각 회전(pass)마다 어떻게 진행되는지 웹에서 한 단계씩 확인할 수 있는 학습용 페이지입니다.

## 파일 구성

- `index.html`: 웹 시각화 페이지 (파일 하나로 동작하며 별도 설치가 필요 없습니다)
- `bubble_sort_pass.c`: 회전마다 결과를 출력하는 C 프로그램

## 사용 방법

1. 배열 값을 입력하고 **적용**을 누릅니다 (2~10개, 1~99 사이의 정수).
2. **다음 ▶**으로 한 단계씩 넘기거나 **▶ 재생**으로 자동 진행합니다.
3. **회전 끝으로**를 누르면 현재 회전이 끝난 상태로 바로 이동합니다.
4. 키보드의 ← → 키로 이동하고, Space 키로 재생/일시정지할 수 있습니다.

## C 프로그램 실행

```
gcc bubble_sort_pass.c -o bubble
./bubble
```
